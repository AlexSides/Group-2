# Car Inventory Management System — PySide6 Version

## Run
1. Install PySide6:
   `pip install PySide6`
2. Put your real photos in an `images` folder beside the Python files if you want auto-linked sample images.
3. Run:
   `python Main.py`

- Inventory
- Locations
- Reports
